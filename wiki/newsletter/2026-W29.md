# WebAssembly Weekly 2026-W29 (7/13〜7/19)

対象期間: 2026-07-11〜2026-07-18(初回のため前回チェック日=07-11起点)

## 今週のハイライト

- **WASI 0.3.x のリリース計画が判明。** 6/25のWASI Subgroup会議の議事録が公開され、0.3.1(8/4: maps・implements・fixed-length lists)→0.3.2(10/6: error context・stream splice/forward)→0.3.3(12/1: cooperative threads)という暫定スケジュールが示された([[2026-06-25-wasi]])
- **Multibyte Array Access が Phase 2 投票へ。** 7/14のCG会議のアジェンダに [Multibyte Array Access](https://github.com/WebAssembly/multibyte-array-access)(Wasm GC配列の複数バイト一括アクセス、Champion: Brendan Dahl)のPhase 2投票が載った。結果は議事録未記入のため来週確認
- コア仕様のproposalフェーズ変化は今週なし
