# Numeric Values in WAT Data Segments

**Phase 2** / Champion: Ezzat Chamudi

## 概要

テキスト形式(WAT)のdata segmentに、文字列リテラルだけでなく数値(`(i32 1 2 3)` のような形)を直接書けるようにするproposal。テキスト形式の書きやすさ改善のみで、バイナリ形式への変更はない。
