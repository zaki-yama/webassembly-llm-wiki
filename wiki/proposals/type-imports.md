# Type Imports

**Phase 1** / Champion: Andreas Rossberg

## 概要

型をモジュール間でimport/exportできるようにするproposal。ホストやほかのモジュールが定義する抽象型(例: ファイルハンドル)を型安全に受け渡しできるようになり、参照型のカプセル化が可能になる。
